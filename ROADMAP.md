# Arah Eksplorasi

[Beranda](README.md) · [Progres](PROGRESS.md)

Ini peta minat, bukan daftar modul wajib. Pilih satu pertanyaan menarik, pelajari dasar yang diperlukan, lalu coba sesuatu yang bisa diamati. Tidak perlu membuat seluruh materi di muka.

| Pintu masuk rasa penasaran | Fundamental yang bisa ditemukan |
|---|---|
| Kenapa website bisa terbuka hanya dengan mengetik nama? | Browser, DNS, alamat IP, request/response |
| Kenapa localhost di HP tidak membuka aplikasi laptop? | Host, loopback, port, jaringan lokal |
| Apa yang sebenarnya dikirim saat menekan tombol login? | HTTP, cookies, session, authentication |
| Kalau tombol admin disembunyikan, apakah aksesnya aman? | Authorization dan pemeriksaan di server |
| Mengapa input biasa bisa mengubah perilaku aplikasi? | Validation, injection, XSS, mitigasi |
| Layanan apa yang sedang “menunggu tamu” di laptop sendiri? | Socket, listening port, service, firewall |
| Apa yang bisa diketahui dengan mengamati trafik lab? | DNS, TCP/UDP, TLS, Wireshark |
| Bisakah memahami program dari cara ia bereaksi? | Reverse engineering JavaScript/API dan program sederhana |
| Bagaimana membuktikan perbaikan keamanan bekerja? | Retest, security testing, secure development |

Tools seperti curl, ip, ss, dig, Nmap, Burp, ZAP, dan Wireshark diperkenalkan saat bisa membantu menjawab pertanyaan. Belum perlu memasang semuanya.

SPMB dan jaringan lab sendiri dapat menjadi tempat eksperimen lebih lanjut setelah konsep terkait siap. Final project tetap menjadi kemungkinan jangka panjang, bukan beban tugas saat ini.

## Pegangan referensi

Saat menyiapkan penjelasan atau eksperimen, AI memakai sumber resmi dan memeriksa versi yang relevan:

- [OWASP Top 10](https://owasp.org/projects/top-ten), [WSTG](https://owasp.org/www-project-web-security-testing-guide/v42/), dan [ASVS](https://asvs.owasp.org/).
- [OWASP API Security](https://owasp.org/API-Security/).
- [PortSwigger Academy](https://portswigger.net/web-security/).
- Dokumentasi resmi Fedora dan tools yang benar-benar digunakan.

Topik-topik ini adalah arah eksplorasi, bukan klaim materi tersedia atau sudah dikuasai.
